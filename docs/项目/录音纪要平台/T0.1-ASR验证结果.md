## 3. 踩到的 3 个坑（写进代码注释了，不要重犯）

| # | 坑 | 现象 | 解决 |
|---|---|---|---|
| 1 | **PyAV 版本** | `TypeError: open() got an unexpected keyword argument 'metadata_errors'` | **必须 `av==13.1.0`**（av 19 与 faster-whisper 1.2.1 不兼容） |
| 2 | **中文变繁体** | 输出满是「個 / 這 / 麼」 | 转写时加 `initial_prompt="以下是普通话的句子，请用简体中文输出。"` |
| 3 | **端口 8000 被占** | 容器 `Created` 但起不来、日志为空 | 本机 8000 已被别的项目占用 → 容器内固定 8000，**宿主机端口走 `ASR_PORT` 映射**（`${ASR_PORT}:8000`） |

补充：
- 容器里**不需要 curl**（slim 镜像没有）→ compose 的 healthcheck 用 `python -c "urllib..."` 写法；
- 本地 `medium` / `large-v3` 缓存**不完整**（只有 3 MB 配置，没有 `model.bin`）→ **当前只能用 `small`**；
- `HF_HUB_OFFLINE=1` + `local_files_only=True` 才能保证不联网。
