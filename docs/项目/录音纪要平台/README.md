## 四条不可违反的约束（出自项目宪法）

1. **交付形态锁定 Web** —— 不做小程序、不做桌面客户端（原则 I）。
2. **不自研模型，只做编排** —— ASR / LLM 全部外部调用（原则 II）。
3. **拿不出证据的"完成"一律算未完成** —— 每个任务必须有可复现命令（原则 III）。
4. **可维护性可判定** —— 每个 commit 前 `tools\check-maintainability.ps1` 必须 exit 0（原则 VII，v1.1.0）。
