## 2. 硬编码自检（每个任务的 DoD 都要跑）

```powershell
cd D:\new\projects\meeting-notes

# 1) 代码里不应出现本机绝对路径 / 回环地址 / 明文 key
Select-String -Path .\app\src\main\java\**\*.java -Pattern 'C:\\','D:\\','localhost','127\.0\.0\.1','sk-','minioadmin'
# 期望：无输出（或仅注释）

# 2) yml 里每个值都应是 ${ENV:default} 形式
Select-String -Path .\app\src\main\resources\application.yml -Pattern '^\s+\S+:\s+(?!\$\{)[^\s#]'
# 期望：只命中 server.port 之外的极少数固定项，逐行确认

# 3) 新增配置项必须在 .env.example 里有对应行
#    允许出现"只在 .env 里、yml 里没有"的项（它们由 docker-compose 消费，不进应用配置）：
#    ASR_IMAGE / ASR_PORT / INBOX_HOST_DIR / POSTGRES_DB / POSTGRES_USER / POSTGRES_PASSWORD
$allowed = @('ASR_PORT','INBOX_HOST_DIR','POSTGRES_DB','POSTGRES_USER','POSTGRES_PASSWORD',
             'REGISTRY_PREFIX','MINIO_PORT','MINIO_CONSOLE_PORT','OLLAMA_PORT',
             'ASR_MODEL_HOST_DIR','PIP_INDEX_URL',
             'ASR_MODEL_NAME','ASR_LANGUAGE','ASR_COMPUTE_TYPE','ASR_BEAM_SIZE','ASR_SMOKE_AUDIO')
$yml = (Select-String -Path .\app\src\main\resources\application.yml -Pattern '\$\{([A-Z0-9_]+)' -AllMatches).Matches |
        ForEach-Object { $_.Groups[1].Value } | Sort-Object -Unique
$env = (Select-String -Path .\.env.example -Pattern '^([A-Z0-9_]+)=' -AllMatches).Matches |
       ForEach-Object { $_.Groups[1].Value } | Sort-Object -Unique
Compare-Object $yml $env | Where-Object { $allowed -notcontains $_.InputObject }
# 期望：无输出（yml 用到的变量都在 .env.example 里；多余项只能是 $allowed 那几个）

# 4) 反向：.env 里定义了但两处都没用到的死配置
$x = (Compare-Object $yml $env | Where-Object { $allowed -notcontains $_.InputObject })
if ($x) { $x | Format-Table -AutoSize } else { 'no diff' }
```

> 第 3 条是"一个不落"的**机器判据**：加了配置却没进 `.env.example`，这个差集就会报出来。

## 3. 例外（允许写死的只有这些，且要能辩护）

| 项 | 为什么可以写死 |
|---|---|
| Docker 内部服务名（`postgres` / `redis` / `minio` / `asr`） | 由 compose 定义，写进 `application.yml` 的默认值即可 |
| 容器内固定路径 `/inbox` | 由 compose 挂载决定 |
| 端口 8080（容器内） | 对外端口已由 `APP_PORT` 控制 |
| 数据库表结构 | 走 Flyway，不在配置范围 |

除上表外，任何"我觉得这样写更方便"的硬编码，都要在 review 时被拒。
