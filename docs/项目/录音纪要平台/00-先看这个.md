## 2. 核心结论速查

| 项 | 结论 |
|---|---|
| **交付形态** | Web（Spring Boot API + 4 个页面 + Swagger），`docker compose up` 一键起。不做小程序/桌面端（D-001） |
| **给谁用** | 11 类用户，**P1 只服务 4 类**：A 本地文件囤积者 / B 数据不能出门 / C 要接进自己系统 / K 短视频信息囤积者（D-003R） |
| **输入** | 8 个入口，P1 只有 UPLOAD / FETCH / PASTE（+ 手机上传、链接 L1/L2）（D-025/D-027R） |
| **闭环** | 采集→转写→结构化→产出→**用户修正**→**术语沉淀回流**（没有 ⑤⑥ 不算完成，D-014） |
| **多场景怎么覆盖** | **一份管线 + 5 个摘要模板**（会议 / 课程 / 访谈 / 播客 / 短视频），不是 5 条管线（D-025） |
| **没有 API key 能不能跑** | 能。ASR 本地免费；摘要三档降级：云 API → 本地 Ollama → **抽取式兜底**（D-020/D-035） |
| **AI 协作基线** | 三准备 + 四规则 + **14 个提示词模板**（D-042，`docs/协作/开发提示词模板.md`） |
| **数据安全** | 可备份 / 可恢复 / 重启不丢；**备份不含 `.env`**，恢复必须 `-Force`（D-023） |
| **链接怎么处理** | L1 确认卡片 → L2 直链探测 → BYOF 接口；**不做内置平台解析器**（D-027R） |
| **不做** | 小程序 / 桌面端 / SaaS 托管 / 会议入会 / DRM / 网盘 / 页面抓取 / 模型训练 / 多用户（v1） |
