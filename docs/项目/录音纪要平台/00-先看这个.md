## 2. 核心结论速查（看完这几行你就知道这项目长什么样）

| 项 | 结论 |
|---|---|
| **交付形态** | Web（Spring Boot API + 4 个页面 + Swagger），`docker compose up` 一键起。不做小程序/桌面端（D-001） |
| **给谁用** | 11 类用户，**P1 只服务 4 类**：A 本地文件囤积者 / B 数据不能出门 / C 要接进自己系统 / K 短视频信息囤积者（D-003R） |

| **闭环** | 采集→转写→结构化→产出→**用户修正**→**术语沉淀回流**（没有 ⑤⑥ 不算完成，D-014） |
| **多场景怎么覆盖** | **一份管线 + 5 个摘要模板**（会议 / 课程 / 访谈 / 播客 / 短视频），不是 5 条管线（D-025） |
| **没有 API key 能不能跑** | 能。ASR 本地免费；摘要三档降级：云 API → 本地 Ollama → **抽取式兜底**（D-020） |
| **生产级证据** | 幂等 / 重试+死信 / 崩溃恢复 / taskId 日志 / 四组件健康检查 / magic number 校验 / SSRF / 配额 / 并发可控 / 缓存 / 配置全外置 / 一键启动 / Flyway / E2E（N1–N20） |
| **数据安全** | 可备份 / 可恢复 / 重启不丢；**备份不含 `.env`**，恢复必须 `-Force`（D-023） |
| **链接怎么处理** | L1 确认卡片（读公开元信息）→ L2 直链探测 → BYOF 接口；**不做内置平台解析器**（D-027R） |
| **不做** | 小程序 / 桌面端 / SaaS 托管 / 会议入会 / DRM / 网盘 / 页面抓取 / 模型训练 / 多用户 |
