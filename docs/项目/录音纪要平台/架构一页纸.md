# 架构一页纸（提示词卡 02 的正式产物）

> 用途：换会话 / 换 agent / 新人接手时，**只读这一页就知道东西放在哪、数据长什么样、哪部分谁负责**。
> 权威依据：`plan.md`（深水区）、`spec.md` §5（页面结构）、`V1__init.sql`（真实表结构）、`decisions.md`（每条取舍）。
> 本页只写"现在的真实状态"，不写愿景；未实现的在文末单列。

---

## 1. 页面与组件放在哪

| 页面 | 路由 | 职责 | 状态 |
|---|---|---|---|
| P1 提交页 | `/submit` | 三类入口（上传/链接/粘贴）+ 提交 + 校验反馈 | 阶段 1（T1.6） |
| P2 任务列表 | `/tasks` | 状态徽章、筛选、批量、重试 | 阶段 1（T1.6） |
| P3 结果详情 | `/tasks/{id}` | 全文 / 摘要 / 待办 / 改词 / 导出 | 阶段 1（T1.6） |
| P4 设置页 | `/settings` | 术语表、配额用量、AI 档位、备份入口 | 阶段 3 |

- **静态页面**（`app/src/main/resources/static/`）+ 原生 JS，**不引入前端构建/框架**（D-001 Web-only，避免 Node 工具链）。
- 组件约定：一个页面一个 HTML + 一个 `*.js`；共用样式 `app.css`；**页面不写死服务地址**（同源相对路径）。
- 交互基线（spec §5.6）：上传有进度与校验反馈；列表 3 秒轮询（D-024，不用 WebSocket）；错误必须给"下一步怎么办"。
- Swagger UI 走 `/swagger-ui`（OpenAPI 由 Spring 生成，见 `接入指南.md`）。

## 2. 接口请求放在哪

**后端分层（`com.meetingnotes.*`，包名即层次，禁止跨层直连）**

```text
web/        Controller + DTO + ApiExceptionHandler   ← 只做参数绑定/状态码，不做业务判断
task/       TaskService（上传编排）+ QuotaService    ← 校验顺序、幂等、配额、落库
upload/     MediaMagic（文件头白名单）+ AudioDurationProbe（ffprobe 真时长）
worker/     TranscriptionWorker（Redis BLPOP → ffmpeg 抽音轨 → ASR → 写结果）
config/     S3StorageConfig / LlmModelSwitchEnvironmentPostProcessor
```

**对外接口（`/api/v1`，字段一律 snake_case，错误体 `{"code","message"}`）**

| 方法 | 路径 | 现状 |
|---|---|---|
| POST | `/tasks`（multipart `file`） | ✅ 已实现（201；幂等返回 `reused:true`） |
| GET | `/tasks/{id}` | ✅ 已实现（状态机 + transcript） |
| GET | `/tasks` | ⏳ 列表（T2.x 前补） |
| GET | `/tasks/{id}/result` | ⏳ 阶段 3 |
| POST | `/tasks/{id}/retry` | ⏳ 阶段 2（死信） |
| GET | `/export` | ⏳ 阶段 4 |
| POST | Webhook（对外推送 HMAC 签名） | ⏳ T4.6 |

**错误码契约（固定，D-041）**：`INVALID_MEDIA`(400) / `SIZE_EXCEEDED`(413) / `DURATION_EXCEEDED`(400) /
`QUOTA_EXCEEDED`(429+`Retry-After`) / `UNAUTHORIZED`(401，T4.6) / `ASR_UNAVAILABLE`(503)。

**队列**：Redis List（`BLPOP` 阻塞取，非轮询）；任务真相在 PostgreSQL `task` 表，Redis 只做"待办通知"。

## 3. 核心数据有哪些字段（7 张表，以 `V1__init.sql` 为准）

| 表 | 关键字段 | 说明 |
|---|---|---|
| `task` | id / user_id / source_type(UPLOAD/FETCH/PASTE/…) / content_hash / duration_sec / size_bytes / status / source_uri / ai_tier / error_code / retry_count | **任务唯一真相**；status ∈ PENDING→RUNNING→DONE / RETRYING→DEAD |
| `task_result` | task_id / transcript / summary / todos(jsonb) / keywords(jsonb) / template | 结构化产物；一个任务一行 |
| `glossary` | wrong_text / right_text / hits / priority | 术语回流（用户修正后沉淀，D-014） |
| `speaker_profile` | speaker / aliases / notes | 说话人档案 |
| `quota` | user_id / day / used_minutes / used_tasks | 每日配额（原子 upsert 防超卖） |
| `dead_letter` | task_id / reason / payload / created_at | 死信（超过重试上限） |
| `webhook_delivery` | task_id / url / signature / status / attempts | Webhook 投递记录（退避重投） |

**状态机（不许出现别的状态）**：`PENDING --消费--> RUNNING --成功--> DONE`；`RUNNING --失败--> RETRYING --重试用尽--> DEAD`；
`RETRYING --再消费--> RUNNING`。崩溃恢复（T2.3）把僵尸 RUNNING 拉回队列。

**幂等键**：`content_hash`（SHA-256，流式计算）+ `user_id` —— 现在靠查询判断（D-040），T2.1 加唯一约束兜并发。

## 4. 哪些事前端处理、哪些必须服务端处理

| 事 | 谁做 | 为什么 |
|---|---|---|
| 上传进度、拖拽、Tab 切换、表单提示 | 前端 | 纯交互，无安全含义 |
| **文件类型判定** | **服务端**（`MediaMagic` 读文件头） | 前端 `accept`/扩展名/MIME 都可伪造（spec N6） |
| **大小 / 时长 / 配额 / 幂等** | **服务端** | 前端校验只是体验，绕过即攻击面；配额是产品规则 |
| 轮询任务状态 | 前端（3s） | 服务端只提供只读状态 |
| ASR / 摘要 / 术语回流 | **服务端 + 容器内 worker** | 密钥、模型、媒体处理都不能下放浏览器（D-010） |
| 重组 Markdown/导出 | 服务端生成 | 保证导出与页面一致 |
| 备份 / 恢复 | 服务端脚本（`backup.ps1`/`restore.ps1`） | 只走命令行，避免误点毁库（D-023） |
| 密钥（LLM/ASR/S3） | **只在服务端环境变量** | 绝不进前端/仓库/日志 |

**底线**：前端不承担任何安全判定；服务端不信任前端传来的任何"已校验"结论。

## 5. 模块关系（谁调谁）

```text
浏览器 ──HTTP──> web/Controller ──> task/TaskService ──┬──> upload/MediaMagic + AudioDurationProbe（ffprobe）
                                                      ├──> QuotaService（PG quota 原子 upsert）
                                                      ├──> MinIO（tasks/{taskId}/ 原文件）
                                                      └──> PG task(PENDING) + Redis 队列
worker/TranscriptionWorker ──BLPOP──> 取 taskId ──> MinIO 取文件 ──> ffmpeg 抽 16k 单声道
                            ──> ASR（OpenAI 兼容，容器内 http://asr:8000）
                            ──> 摘要（三档：云 LLM → 本地 Ollama → 抽取式）
                            ──> 写 task_result + task(DONE) ──> Webhook（阶段 4）
```

**AI 三档（D-020）**：① 云 OpenAI 兼容（DeepSeek/智谱…，有 key 才启用）② 本地 Ollama（可选）③ 抽取式零依赖兜底；
`ai_tier` 落库，结果里能看出用的哪档。**没有 key 也能跑**（D-035/D-036）。

## 6. 部署形态与端口

| 容器 | 镜像来源 | 端口（宿主） | 说明 |
|---|---|---|---|
| `app` | 本地 build（JDK 21 + ffmpeg） | `APP_PORT`=8080 | Spring Boot + 内嵌 worker |
| `asr` | 本地 build（`infra/asr/`，faster-whisper small） | `ASR_PORT`=8001 → 容器 8000 | OpenAI 兼容转写 |
| `postgres` | `REGISTRY_PREFIX` + `library/postgres:16-alpine` | 内部 5432 | 真相库；Flyway 管表 |
| `redis` | `REGISTRY_PREFIX` + `library/redis:7-alpine` | 内部 6379 | 队列 |
| `minio` | `MINIO_IMAGE`（D-038） | 9000/9001 | 原始媒体 + 对象 |
| `ollama` | `OLLAMA_IMAGE`，`profiles: local-llm` | — | 第二档 AI（默认不启） |

一键起：`docker compose up -d` → 5/5 healthy；健康检查打 `/actuator/health`（DB/Redis/MinIO/ASR 四项）。
配置全部走 `.env`（唯一事实来源 `配置清单.md`），**代码里不许有路径/端口/key 硬编码**。
