## 3. 怎么用（T4.12 真实库回归）

```powershell
# 1) 起服务
cd D:\new\projects\meeting-notes
$env:ASR_PORT='8001'; docker compose up -d asr

# 2) 逐个提交（P1 上传接口做好之后）
Get-ChildItem D:\datasets\meeting-notes-samples -File |
  Where-Object { $_.Extension -in '.wav','.mp4' } |
  ForEach-Object { curl.exe -s -X POST http://localhost:8080/api/v1/tasks -F "file=@$($_.FullName)" }

# 3) 断言：全部任务到 DONE，且记录总耗时
```

**验收标准**（写进 `任务清单.md` T4.12）：

- 11 个文件全部到达 `DONE`；
- 最长 56.7 min 的文件不被拒绝（验证 D-028 的 60 min 上限）；
- 记录：总耗时、平均 RTF、失败数（应为 0）；
- 同内容对（mp4 vs wav）的转写文本相似度 ≥ 90%。
