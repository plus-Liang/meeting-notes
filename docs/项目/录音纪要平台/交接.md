## 2. 别踩的坑（最高频）

1. **先 commit → 再 build/up → 再全量**（K-68/K-77）；改 `static/` 必重建 app 镜像并对服务端 sha256 比对原始字节。
2. **Lead 不写产品代码**（K-63）、**不验收自己的代码**；写码方单 commit 不 push；文档只改 `D:\new\docs\...` 权威版再 `tools\sync-docs-to-code.ps1`——**写码方在代码仓改过的 docs 必须先回灌**，否则 sync 会静默覆盖（K-195）。
3. **门禁三种写法都要跑**（无参 / 反斜杠 / 正斜杠）；行数一律 python `splitlines()`，`Measure-Object -Line` 会数错（K-182）。
4. **卡面白名单必须含 `app/src/test/java/**`**：给 INSERT 加列会打破既有 mock 的 matcher 数量（K-192）。
5. **「单事务」不能只靠 mock**：必须真栈造失败并核对所有被写列的终态（K-197）；新不变量对历史行不成立时，文档要写「对 V<N> 之后成立」（K-198）。
6. **日志里有 id ≠ 链路串起来**：透传类卡必须做任务级配对（DB ↔ 日志逐条，K-191）。
7. **PowerShell 五件套**：`python - <<'PY'` 不存在（写文件再跑，K-196）；脚本命名不能遮蔽标准库（`http.py` 会让 `urllib` 整个崩）；命令行别传 JSON（落 `.json` 文件）；`docker logs > f` 落 UTF-16（K-193）；`Out-File -Encoding utf8` 写提交信息带 BOM（K-179）。
8. **compose `ports:` 是追加**、shell 变量不进容器：改端口用 `$env:APP_PORT=…`，改环境变量写 `environment:`（K-194）。
9. **`deploy-main.ps1` 只重建 app**：compose 级改动（restart/环境/端口/卷）必须另跑一次全量 `docker compose up -d`（K-155）。
10. **`docker kill`/`docker stop` 不触发自愈**：验证 restart 策略要让 PID1 自退（K-154）。
11. **同账号反复错登会触发锁定短路**，测时序/耗时必须换用户名（K-180）；停库实验要覆盖 Hikari 30s 超时（K-189）。
12. **陈旧 PENDING 夹具会被 2 分钟清扫器抢走**：采样要抢在清扫前（K-190）。
13. **隔离栈多文件 override**：镜像覆盖用 `build: !reset null` + `image:`；探针要证明指向本栈（K-110）。
14. **真浏览器验收**：系统 Edge + `playwright-core`（`channel:'msedge'`），真实指针点击，别用 `evaluate(el.click())`（K-117）；前端卡验收后必须重建主栈并在 8080 复验（K-136/D-210）。
