## 1. 怎么做到"不用你提醒，自动用起来"（三层触发）

1. **规则层（最硬）**：`AGENTS.md` §0 第 4 步 + §7 —— 任何"做项目/做产品/新功能/要计划/要发布"的请求，**先跑阶段判定**再动手。DSH 每个会话自动加载 AGENTS.md。
2. **技能层（任何工作区）**：`vibe-coding-framework` 的 description 带触发词（我想做/开发一个/立项/PRD/技术方案/拆任务/上线/发布/复盘…），命中就加载。
3. **文档层（人看）**：本文件 + `技能路由表.md` + `日常怎么用.md`。

**你只需要说人话**："我想做一个 XX"、"帮我看看这个项目还差什么"、"该发布了吗" —— 我会先给 `阶段判定 → 本阶段必做 → 门禁差什么 → 第一步`，再动手。
