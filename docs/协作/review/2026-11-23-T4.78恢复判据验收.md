## §4 建议（非阻塞）

- **S1 时钟假设显式化**：cutoff 用 `StalePendingQueries.cutoff()`（JVM 时钟）而非 PG `now()`。单机同容器没问题，但「app 与 DB 分主机 / 时区不一致」时会整体偏移（D-067 已登记该假设）。建议在 `配置清单.md` 的键说明里补一句「JVM 与 PG 须同时钟同 TZ」，或后续改为 `now() - make_interval(mins => ?)`。
- **S2 回退可观测性**：≤0 目前只打 WARN，运维侧看不到。可在 `/actuator/health` 的 readiness 细节或启动摘要里带一个 `recoveryStaleMinutesEffective`（可选，非本卡必需）。
