## 三、代码复核要点

- `ShareTokens`：32B SecureRandom → base64url（43 字符）+ SHA256 hex；生成与 hash 分离，DB 只有 hash。
- `ShareService.create`：404 口径同删除、非 DONE 400、TTL 读 `app.share.ttl-days`（默认 7）；`revokeAll` 用 `update` 受影响行数（软撤销）；`existsActiveByHash` 未撤销+未过期。
- `ShareController.view`：两次查（exists + 12 键 join）；JSONB 解析容错（坏 JSON → 空集合，不炸匿名接口）；`original_name` 只从 `source_uri` 尾段派生，不泄露完整对象路径。
- `ApiTokenFilter.shouldNotFilter`：先判 `/api/v1/share/` 前缀 → 豁免；其余 `/api/v1` 照旧 401；路径穿越实测无绕过。
- 前端：`share.html` 无 token 弹窗/无写入口/不链内部页；`task.html` 分享区（生成/复制/有效期/撤销全部 + 二次确认）。
