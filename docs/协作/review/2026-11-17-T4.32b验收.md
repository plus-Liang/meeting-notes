## 五、代码与卡面核对（我读了实现）

- `OgMetaParser`：纯函数**不抛**；`<meta property|content>` 两种属性顺序都兼容；`og:title`/`og:image`/`og:video:duration`，兼容 `og:audio:duration` 与 `itemprop="duration"`；时长支持 ISO 8601（`PT1M2S`/`PT90S`/`P1D`）与纯秒数，负数/超 24h 不采信；无 og 回退 `<title>`，都没有 → null；只解 5 个常见实体。
- `LinkPreviewService`：**复用同一道 `UrlGuard`**；匿名 GET、手动跟随重定向且**每跳重校**；**只读前 `preview-max-bytes`（默认 2MB）不整页进内存**；分类 `audio/*`、`video/*`、`application/octet-stream` → direct，`text/html` → page，其它 → unsupported + 可读 reason；相对 `og:image` 按 final_url 补全（非法则原样返回不抛）。
- `ProcessMediaFetcher`：命令**按空格拆 argv、不过 shell**；`{url}` 必填且必须**独立 token**（`--url={url}` 会被判配置错误 → 500 INTERNAL_ERROR，不静默拼串）；`{out}` 可选；stdout 模式流式落盘受 `max-bytes` 限制（413 并删残留）；**看门狗从进程启动起算**（sleep 到点 `destroyForcibly`，用 `timedOut` 标记区分"超时"与"异常退出"——stdout 模式读阻塞也兜得住）；stderr 旁路线程排空并保留尾部 200 字进错误文案；非 0 退出/启动失败 → 502。
- `LinkTaskService`：`use_byof` 归一化（缺省 false，**32a 请求体语义不变**）；未配置在**建临时文件之前**就 400 `FETCHER_UNAVAILABLE`（无副作用）；BYOF 分支在 fetcher 内仍先过 UrlGuard。
- 前端：预览/提交期间禁用防重复；direct/page+BYOF/page 无 BYOF/unsupported 四分支与卡面一致；封面用 `insertAdjacentHTML` 但**引号已转义**、标题走 `textContent`；错误就地提示不白屏。
- 配置三处一致（yml / `.env.example` / `配置清单`）；`接入指南` 码表**只增**到 10 个业务码；README 写了"仓库不含平台解析器、BYOF 自负合规责任"（D-027R）。
