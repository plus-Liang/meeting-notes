## 5. 观察与遗留

1. **`.minio.sys` 文件数不守恒**（423→406）：MinIO 重启后清理临时分片所致，属正常；文档与脚本判断备份完整性应看 `manifest.minio_objects` 快照值与恢复后的业务目录数，不要拿 `find /data -type f` 总数硬比。
2. **备份体积 473 MB**（299 个任务音频），恢复耗时约 60s；建议运维文档提示磁盘预留 ≥ 2× 数据量。
3. **空库首启时模型目录**：drill 一开始把 `ASR_MODEL_HOST_DIR` 指到空 `./models`，asr 按设计打印中文提示并退出（说明"模型缺失"提示确实可读、可行动），改指真实缓存后 5/5 healthy。
4. **PowerShell 5.1 传 JSON 给 curl.exe 的内联参数会被拆坏**（同一 payload 内联 → `400 INVALID_PARAM`，写临时文件 + `--data-binary "@file"` → `201`）——验收脚本一律用文件体，见 **K-97**。
5. 未做：真实故障注入（杀容器/断网）、备份到异地、恢复期间的并发写入压力。
