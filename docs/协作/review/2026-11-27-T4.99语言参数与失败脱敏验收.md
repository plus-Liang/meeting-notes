## 六、建议（S1–S5）

- **S1（中，责任在我）卡面白名单漏了调用链中段**：`TaskController` / `LinkTaskController` / `PasteRequest` / `LinkRequest` 四个 web 文件不在白名单，但「三入口接受 language」必然要改它们。写码方主动声明了，我接受；教训入 K-237。
- **S2（中）`auto` 分支仍带中文 `INITIAL_PROMPT`**：`server.py` 只在「显式非 zh」时置空 prompt；`auto` 走 `lang=None`，中文 prompt 仍会注入，英文音频的自动检测可能被带向中文。建议 auto 也置空（或先检测再决定）。
- **S3（低）行数顶格**：`TaskController` 302→300 是压缩自己新增行换来的；`index.html` 981/990、`tasks.html` 1249/1250 都已顶格（K-233 复现）⇒ 下一张动这些文件的卡必须先拆分。
- **S4（低）字幕路径静默忽略 language**：`TaskController` 对 `.srt/.ass` 直接 `createSubtitle(file, template)`，传了 `language` 被静默丢弃；建议文档写明「文本任务不受 language 影响」或对字幕传 language 返回 400。
- **S5（低）PASTE 任务的 language 无意义**：`TextTaskService` 也落 `task.language`，但纯文本不走 ASR，字段值只是噪声；无害，建议在接入指南一句话说明。
