## 六、建议（S1–S5）

- **S1（低）`state==='ready'` 时「录制标签页声音」仍可点，点击静默无反应**：`index-page.js:581` 的 `if (state !== 'idle') return;` 直接返回，用户看到的是「点了没反应」。建议 ready/uploading 状态也 `disabled`，或提示「请先提交或丢弃当前录音」。可复现：录完不提交 → 点该按钮 → 无任何反馈。
- **S2（低）错误提示与普通提示同色**：未勾音频走 `showRec('error', …)`，但 `#recMsg` 只有 `hint` 基类，视觉上没有区分。可接受（文案已明确「已取消」），若要强化可在 `components.css` 加 `.rec-error`。
- **S3（低）标签页录音未提交前存在内存里**：刷新页面即丢，与麦克风录音一致；建议 README 加一句「录完尽快提交」。
- **S4（中）「标签页」是承诺、实现不强制**：用户若选整屏 + 系统音频，会录到整个系统混音（能力大于承诺）。建议文档补一句「也可以选整屏，但录到的是系统混音，可能含其他声音」，避免下次「录到不该录的」投诉。
- **S5（低）`MediaRecorder` 产物体积与上限**：60 分钟 webm/opus 约 30–60 MB，仍在 200 MB 内；但蓝牙/静音场景码率会更高，建议运维口径记一笔「长录音先看体积提示」。
