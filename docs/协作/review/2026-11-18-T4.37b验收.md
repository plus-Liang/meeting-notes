## 二、代码核对（我读了 diff，不只跑测试）

- **登录页**（`login.html`，新增 154 行）：登录/注册双模式；提交用**裸 `fetch`**，不带 `Authorization`（我抓到真实请求头 `authorization=None`）；成功后写 `localStorage.mn_token/mn_user` 再 `location.replace(安全 next)`；错误就地文案（401/409/403/400/网络）；注册模式前端先校验用户名 3–32、密码 ≥8、两次一致，**不合法不发请求**（我实测请求数不变）；`submitting` 闸 + 按钮禁用防双击。
- **防开放重定向**（`auth.js` `mnSafeNext`）：字符白名单 `[A-Za-z0-9_\-./?=&%]+`（**冒号不在集合 → `http:`/`javascript:` 天然被拒**）+ 拒绝 `//` 开头；非法一律回 `index.html`。`?next=` 为空/合法时才拼 `next=`，且 `encodeURIComponent`。
- **401 处置**（`apiFetch`）：清 `mn_token/mn_user` → 非 `login.html`/`share.html` 才 `mnGoLogin(当前 pathname+search)`；`login.html` 不跳（防循环）；**`share.html` 保持匿名只读**（只引入 `auth.js`、无页头占位、无登录态写入，我实测匿名可正常渲染）。
- **退出**：`mnLogout` 先 `POST /auth/logout` 吊销服务端令牌（无论成败）→ 清本地 → 回登录页；我实测旧令牌随后打 API **401**。
- **页头用户区**：4 个业务页 `</nav>` 前 `[data-mn-userbar]`；用户名经 `mnEscapeHtml` 转义（XSS 面收口）；`mn_user` 缺失时用 `GET /auth/me` 兜底一次；`share.html` 不加占位（匿名只读不变）。
- **文档**：`接入指南.md` §3 开头改为「浏览器统一走登录页，`API_TOKEN` 只用于外部接入」；权威版与代码仓副本逐行一致（`sync-docs-to-code.ps1` 已跑）。
- **无前端泄漏**：`static/` 全量搜不到 `API_TOKEN` 字面值（仅注释提及）；`login/register` 请求不带 Bearer；`audio` 仍走 T4.37a `u=` 三段签名（不含 API_TOKEN）。
