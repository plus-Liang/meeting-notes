## 2. 我额外发现的问题

### O-1（P3，已出卡 T4.65）`-Repo` 传正斜杠时 M-12 豁免失效

同一个仓库、同一次改动，只改一个参数：

| 调用方式 | 结果 |
|---|---|
| `check-maintainability.ps1`（无参，内部用相对路径） | 阻塞 0 / 提示 **0** |
| `-Repo "D:\new\projects\meeting-notes"`（反斜杠） | 阻塞 0 / 提示 **0** |
| `-Repo "D:/new/projects/meeting-notes"`（**正斜杠**） | 阻塞 0 / 提示 **4**（`components.css 982 行` / `index.html 929` / `task.html 1386` / `tasks.html 1095`，全是已有 `M-12|` 豁免的文件） |

原因：`M-12|相对路径` 的豁免键用 `\` 拼，而 `-Repo` 带正斜杠时算出的相对路径是 `app/src/main/...` 混合分隔符，`Select-String -SimpleMatch` 匹配不上。**阻塞项不受影响（仍 0）**，只是提示数量变了——写码方在 T4.62 就报告过这个现象，我当时只当"既有行为"放过，这次复核确认是真 bug（会让"用 -Repo 指路"的人看到 4 条假提示）。

### O-2（P4，仅登记）`QueuePublisher.java:52` 的方法注释仍偏向旧调用方

`/** 不抛版本：供 worker 重投等调用方自行回退状态（S6），失败记 WARN 不中断调用方流程。 */` —— worker 重投现在走 `tryPublishToTail`，`tryPublish` 的实际调用方是 `StartupRecovery`。类级注释已改对，方法级这句仍是旧口径，属残留 cosmetics，不单独出卡（并入 T4.65 的可选清理项）。
