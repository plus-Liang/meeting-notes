## 五、建议（不阻塞）

- **S1**（低）`ASR_MODEL_HOST_DIR` 写相对路径时，脚本按「仓库根」解析、compose 按「compose 文件所在目录」解析；本项目两者同根所以等价，但若将来 compose 文件挪位置就会分叉——建议在配置清单加半句「相对路径以仓库根为准」。
- **S2**（低）撞车检测用 `ConfigFiles` 前缀比较；同一仓库若通过符号链接/短路径被两处挂载会误判为撞车。可在报错文案里提示「若确认是同一目录，请显式设置 `COMPOSE_PROJECT_NAME`」。
- **S3**（低）`$env:` 覆盖优先于 `.env`（与 compose 一致），但 README 未写；建议补一句，避免用户改了 `.env` 不生效的困惑。
- **S4**（提示）建议 first-run 结束时打印一行汇总：`项目名=<x>；模型根目录=<y>；访问地址=<z>`，让用户一次看清关键状态。
